          实际操作指南以下是命令与检查点，不会在浏览器中执行，也不会模拟“测试通过”。
        
    
        
    
          
    
            01 环境与配置
            
    准备启动条件
    
            
    
              安装 Docker、Compose ≥ 2.20 与 Python
              3.12+。首次需要下载镜像和依赖。已有数据库升级前先备份。
            
    
            
    python scripts/deploy.py check
    
            
    自动生成随机凭据；再次执行复用 .env。
    
          
    
          
    
            02 启动与就绪
            
    一条命令启动完整栈
    
            
    python scripts/deploy.py
    
            
    
              MySQL TCP 可用 → db-init 成功 → 业务服务就绪 →
              网关。只有网关暴露主机端口。
            
    
            
    python scripts/deploy.py status
    
            
    
              /health表示进程存活；/ready检查依赖是否就绪。
            
    
          
    
          
    
            03 业务验收
            
    验证最终结果
    
            
    python scripts/deploy.py test
    
            
    
              真实 HTTP、MySQL、Redis、RabbitMQ 和
              WebSocket。检查订单数量、金额、重复提交、越权和注销。请在隔离测试环境运行。
            
    
            
    
              源码：tests/test_live.py、tests/test_broker.py。
            
    
          
    
          
    
            04 故障实验
            
    停止 MQ，再恢复
    
            
    docker compose stop rabbitmq
docker compose start rabbitmq
    
            
    
              停止期间确认请求仍被受理且 Stream 保留；恢复后按请求 ID
              确认只生成一张订单。MQ 停止时不能用完整 Compose
              启动命令代替纯观察。
            
    
            
    
              自动实验见 tests/test_faults.py 与 GitHub Actions。
            
    
          
    
          
    
            05 日志与停止
            
    保留数据再启动
    
            
    python scripts/deploy.py logs
python scripts/deploy.py down
    
            
    
              down保留数据卷。不要用删除卷的方法“修复”库存和订单异常。
